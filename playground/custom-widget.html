⌂ 枢纽

属性面板挂自定义 widget 活例：词表声明 kind: 'vec2'、注册位 widgetComponents: { vec2: Vec2Widget } 指名接管——嵌套对象型 data（pos = { x, y }）内建五型表达不了的结构走这里，别在面板旁 自写宿主表单（首消费者实测的真实弯路）。

props 契约 { value, def, onCommit }：组件只产值，提交经 onCommit 整对象回写（内部接 controller.setNodeData 恰一张快照可撤销）。节点体同一注册位（CanvasView 同形 props）。

试手：点 m1 改位置一轴（读数面 canUndo 翻 true、撤销即回跳）； 点 m2（data 无 pos 键——宽松读 0/0 不炸）；点 k1（无 widgets——面板回退只读 JSON 展示）。
